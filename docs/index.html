Real-Time Drop Tower Emergency-Stop Controller

An ESP32-S3 and FreeRTOS project comparing interrupt-to-task response latency using a binary semaphore and a direct task notification.

Project Overview

This project models an industrial emergency-stop controller for a drop-tower attraction. Pressing the emergency-stop button generates a GPIO interrupt that wakes two FreeRTOS responder tasks.

The project compares a binary semaphore and a direct task notification under idle, loaded, and fault-injection conditions. It demonstrates how task priorities, processor load, and ISR design affect real-time response latency.
