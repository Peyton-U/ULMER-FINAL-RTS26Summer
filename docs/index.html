Real-Time Drop Tower Emergency-Stop Controller

An ESP32-S3 and FreeRTOS system that compares interrupt-to-task wake latency using a binary semaphore and a direct task notification.

Home Architecture Results & Analysis Reflection

Project Overview

This project models an industrial emergency-stop controller for a drop-tower attraction. A GPIO interrupt detects the emergency-stop button and wakes two FreeRTOS bottom-half tasks so their response latency can be measured under idle and loaded processor conditions.
